# 扫雷 Minesweeper

一个用纯 HTML + CSS + JavaScript 写成的单文件扫雷小游戏，无任何依赖，浏览器打开即可玩。

## 玩法

- **左键**：翻开格子
- **右键**：未翻开的格子插旗 / 取消旗
- **数字格**：雷标够则直接展开周围；标多了数字会红闪报错；标少了不展开
- **自动标雷**：默认开启——数字格周围未开的格子数恰好等于数字时，自动把未插旗的格子标为雷（可通过状态栏按钮切换为手动模式）
- **无猜模式**：状态栏可切换「普通 / 无猜」。无猜模式下每次新开局都会自动验证棋盘能否纯靠逻辑推理通关，不会出现只能靠 50/50 猜雷的终局（新开局生效）
- 首次点击必安全，不会踩雷
- 切换页面（标签页）时计时自动暂停，切回来继续计时

## 模式

| 模式 | 棋盘 | 雷数 |
| --- | --- | --- |
| 简单 | 9×9 | 10 |
| 中等 | 16×16 | 40 |
| 困难 | 16×30 | 99 |
| 自定义 | 最多 100×100 | 最多 999 |

## 打开方式

直接用浏览器打开 `index.html` 即可，不需要服务器，也不需要安装任何依赖。

## 文件说明

- `index.html`：游戏全部代码（界面样式和游戏逻辑都在这一个文件里）
